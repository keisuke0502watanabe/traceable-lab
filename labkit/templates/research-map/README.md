# Research フォルダの地図とルール

研究・教育・事務のファイルは、すべてこのフォルダの下に置く。
プログラム（git で管理するもの）だけは別の場所（例: `~/Projects`）に置く。
迷ったらこのファイルを見る。ルールを変えたら、このファイルを直す。

## フォルダ

| フォルダ | 入れるもの |
|---|---|
| `0-受け皿` | どこに置くか迷ったもの。週に1回、下のどれかへ振り分ける |
| `1-執筆` | 書いている原稿、投稿論文、査読、寄稿。`業績/` は自分の論文の最終版 |
| `2-発表` | 発表・講義のスライド。`1-conference/年/発表名/` |
| `3-文献` | 文献 PDF（文献管理ソフトから参照する） |
| `4-データ` | 実験のプロジェクト。一つずつ `labkit init` で作る |
| `5-ラボ・教育` | 研究室、学生、実習、名簿 |
| `6-事務・研究費` | 申請書、研究費の執行書類（`<種類>_<開始年度>_<課題番号>/<年度>/`）、経費 |
| `9-アーカイブ` | 古いもの。中身は整理しない |

## 新しいものが来たら

| 新しく来たもの | 置き場所 |
|---|---|
| 迷ったとき | `0-受け皿` |
| 文献 PDF | 文献管理ソフトに取り込む（PDF 本体は `3-文献`） |
| 新しい発表 | `2-発表/1-conference/年/発表名/` |
| 実験データ | `4-データ/プロジェクト名/DATA/` |
| プログラム・解析ツール | git のフォルダ |

## ルール

- **過去の発表のパワポはコピーしない。** 使ったときは正本の場所を `ref.md` にメモする
- **ファイルは消さない。** 不要と思ったら `_重複/` や `9-アーカイブ` へ移す
- **フォルダを動かしたら `MOVES.md` に記録する。**（元の場所 → 新しい場所）
- **プログラムが場所や名前を前提に読んでいるフォルダがある。** 動かす前に各フォルダの `README.md` を見る
- ファイル名の末尾に空白を入れない
