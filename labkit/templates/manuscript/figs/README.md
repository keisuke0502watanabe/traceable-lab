# 論文の図の規格

- 一図一本: `figNN_<内容>.py` → `out/figNN_<内容>.pdf`（と確認用の .png / .svg）
- データは解析フォルダから読む: `../../../analyses/<ana_id>/out/…`。生データを直接読まない
- 図の下（またはファイルのメタデータ）に根拠の ana_id を残す。投稿用に消すのは最後
- 大きさ: 1 段 85 mm / 2 段 175 mm。フォントは 7–9 pt
- 色は論文・スライド・ポスターで共通にする（相や試料ごとの色をここに書いておく）
  - 例: 相 A `#1462a8` / 相 B `#b8452a` / 相 C `#2f8f6b`
- `out/` は生成物。直すのはスクリプト
