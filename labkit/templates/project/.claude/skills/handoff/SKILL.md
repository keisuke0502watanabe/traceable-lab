# 申し送りを書く

ファイル: 作業の場所に応じて
- 解析の流れ全体 → `notes/HANDOFF_YYYY-MM-DD.md`
- 発表 → `reports/talk-<名前>/START-HERE.md` と `handover.md`
- 論文 → `Documents/manuscript-<名前>/PROGRESS.md`（状態表を更新）

`notes/HANDOFF_TEMPLATE.md` の骨組みに沿って書く。必ず入れるもの:

1. **新しいチャットの最初の一言** — そのまま貼れば再開できる一文
2. **読む順番** — ファイルのパスと、どの節か
3. **一行でいうと** — 出ている成果物、作業中のもの、誤りが分かっているもの
4. **決まったこと** — 日付と根拠（ana_id）つき
5. **待っているもの** — 相手と中身
6. **やってはいけないこと** — このプロジェクトの禁止と、この作業に固有の禁止

会話の記憶に頼らず、ファイルだけで再開できるかを読み返して確かめる。
