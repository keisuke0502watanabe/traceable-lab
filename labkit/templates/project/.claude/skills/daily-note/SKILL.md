# 日誌を書く

ファイル: `notes/YYYY-MM-DD.md`（今日の日付。あれば追記）。

一項目 = 箇条書き一つ。太字の見出しのあとに、

- 何をしたか（ユーザーの指示は「ユーザー『…』」と短く引用）→ `ana-…`（回した ana_id）
- 分かったこと 1–3 行（数値は単位つき）
- 捨てた方向と、その理由
- 確かめること・次にやること（相手がいれば誰に）

書かないこと: 計算の途中経過、コードの全文（それは解析フォルダにある）。

例:

```markdown
# 2025-11-04

- **相図の描き直し**（ユーザー「相図を描き直す」）→ `ana-20251104-mix-phase-diagram`（233 ラン）。
  共晶線 36.8 / 35.0 / 33.2 °C。純試料の 4 本が低くばらつく点は測定者に確認する。ギャラリー更新済み
- **次回**: 融解後に小角側だけ残るピークを追う（候補の走査 4 本は ana-… の peaks.csv）
```
