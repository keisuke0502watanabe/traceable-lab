# reports/

人に見せるもの（レポート・図・発表）と、その根拠になった解析（ana_id）の対応表 `index.csv`。

- `figure_gallery.html` — 全解析の図を並べた一覧（生成物。`labkit gallery`）
- `analyses_viewer.html` — 解析の系譜（試料 → 系統 → 版）と、入力の測定・notes を見るビューア（生成物）
- `index.csv` — レポート ↔ ana_id。`used_for` は「どこに出したか」（申請書、議論、論文の図番号）
- `talk-<名前>/` — 発表（`labkit talk <名前>` で雛形）

新しいレポートは図名か脚注に ana_id を入れる。
